# Travel Assistance Site

## Description
Ce projet est un site web d'assistance voyage qui permet aux utilisateurs de choisir leur destination de rêve et de commencer leur démarche d'obtention de visa avec notre assistance. Le site présente plusieurs destinations populaires et offre une version premium pour des services supplémentaires.

## Structure du projet
Le projet est organisé comme suit :

```
travel-assistance-site
├── index.html          # Page principale du site
├── css
│   └── styles.css     # Fichier CSS pour le style du site
├── assets
│   ├── destinations    # Dossier contenant les images des destinations
│   │   ├── paris.jpg   # Image de Paris
│   │   ├── dubai.jpg   # Image de Dubaï
│   │   ├── bali.jpg    # Image de Bali
│   │   ├── rome.jpg    # Image de Rome
│   │   └── tokyo.jpg   # Image de Tokyo
│   └── icons           # Dossier contenant les icônes
│       └── logo.svg    # Logo du site
└── README.md           # Documentation du projet
```

## Installation
1. Clonez le dépôt sur votre machine locale.
2. Ouvrez le fichier `index.html` dans votre navigateur pour visualiser le site.

## Utilisation
- Naviguez à travers les différentes sections pour explorer les destinations.
- Cliquez sur les boutons "Réserver" pour effectuer une réservation ou "Demander un visa" pour commencer le processus de demande de visa.
